# 架构说明

## 节点

| 节点 | 角色 | 主要职责 |
| --- | --- | --- |
| `k8s-master` | Control Plane | API Server、Scheduler、Controller Manager、etcd、kube-proxy |
| `k8s-worker` | Worker | kubelet、containerd、kube-proxy、Flannel 和业务 Pod |

## 请求链路

```text
客户端
  ↓ NodePort
节点上的 kube-proxy
  ↓ Service Endpoint
nginx-demo Pod:80
```

NodePort 是集群级入口。请求到达 Master 或 Worker 后，由该节点的 kube-proxy 转发到 Ready 的后端 Pod。Endpoint 是 Service 当前可用 Pod 的动态地址清单。

## 监控链路

```text
node-exporter          → 节点 CPU、内存、磁盘、网络
kube-state-metrics     → Kubernetes 对象状态
Metrics Server         → kubectl top 的实时资源指标
Prometheus             → 拉取并存储时间序列指标
Grafana                → 查询、可视化和告警展示
```

Metrics Server 主要服务于 `kubectl top` 和资源管理；Prometheus 负责长期指标采集和 PromQL 查询，两者用途不同。
